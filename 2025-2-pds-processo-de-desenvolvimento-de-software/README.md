# PDV com Scrum: Processo de Desenvolvimento de Software

Sistema de ponto de venda (PDV) para pequenos comércios, desenvolvido em grupo com Scrum: backlog e quadro no Jira, quatro sprints com entrega em vídeo ao fim de cada uma, documentação e apresentação final.

## Sobre o projeto

O sistema atende dois perfis:

- **Operador de caixa**: venda por código de barras ou código interno, busca de produto por nome, cálculo de troco, remoção de item do carrinho e abertura/fechamento de caixa;
- **Administrador**: cadastro de produtos, entrada de estoque, estorno de venda, relatórios por período e gestão de usuários.

Nesta pasta:

- `historias-de-usuario.md`: as 10 histórias de usuário do backlog inicial;
- `PDS - Entregas e Tarefas 01.pdf`: meu documento de organização do grupo, com o que cada uma das 4 entregas exigia, o roteiro da documentação final e a divisão das primeiras tarefas (eu fiquei com a criação do backlog no Jira).

## Código

O código está na organização do grupo no GitHub: https://github.com/pdv-pds

- [`pdv.api`](https://github.com/pdv-pds/pdv.api): API em Java;
- [`pdv.ui`](https://github.com/pdv-pds/pdv.ui): primeira interface web;
- [`meucadinho`](https://github.com/pdv-pds/meucadinho): versão final do PDV ("Meucadinho"), em TypeScript, com o README de documentação que eu escrevi (telas, histórias, metodologia e resultados).
