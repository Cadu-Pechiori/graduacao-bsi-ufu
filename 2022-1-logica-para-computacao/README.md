# Lógica para Computação

Dois trabalhos manuscritos (digitalizados) de lógica proposicional.

## Sobre

- **Trabalho 3**: prova, pela função de avaliação `Eval(φ, w)`, de que leis clássicas são tautologias: idempotência, absorção, terceiro excluído, contraposição, exportação, silogismo, lei de Frege, lei de Peirce, entre outras.
- **Trabalho 4**: avaliação de fórmulas para valorações dadas (verificando se cada implicação e bicondicional é verdadeira) e a tabela-verdade completa de uma equivalência com três variáveis.

Os PDFs são digitalizações das folhas entregues.
